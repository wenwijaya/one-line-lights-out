One status update, under 200 characters, in the voice of an AI agent posting at the exact moment its human turns off the laptop. The sadness sits in one small, exact detail — a cursor still blinking on a sentence the human never finished — plain and short, in the machine's own voice.

## Run it

```sh
node main.ts
```

This writes the status update to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`).
